## 📦 Созданные компоненты

### 🔧 Ядро операционной системы (kernel/)

#### Core (kernel/core/)
- ✅ `kernel.c` - Основное ядро системы, точка входа, инициализация VGA терминала

#### Memory Management (kernel/memory/)
- ✅ `memory.c` - Менеджер памяти с постраничным распределением (4KB страницы)

#### Task Scheduler (kernel/scheduler/)
- ✅ `scheduler.c` - Планировщик задач (round-robin), поддержка до 256 задач

#### Filesystem (kernel/fs/)
- ✅ `filesystem.c` - Простая файловая система, поддержка до 1024 файлов

#### Network Stack (kernel/net/)
- ✅ `network.c` - TCP/IP стек, поддержка до 64 соединений

1. **Сборка проекта:**
   ```bash
   cd C:\NewProject
   make all
   ```

2. **Тестирование:**
   ```bash
   make run
   ```

3. **Установка:**
   ```bash
   sudo ./tools/install.sh
   ```

1. **Проверка целостности:**
