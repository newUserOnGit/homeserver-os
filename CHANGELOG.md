# Changelog

Все значимые изменения в проекте Home Server OS будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Планируется
- Поддержка Docker контейнеров
- Интеграция с облачными хранилищами
- Мобильное приложение для управления
- Поддержка IPv6

- Автоматическое обновление системы

## [0.1.0] - 2026-05-07

### Добавлено
- Базовое ядро операционной системы
- Менеджер памяти с постраничным распределением
- Планировщик задач (round-robin)
- Простая файловая система
- TCP/IP сетевой стек
- ATA/SATA драйвер для дисков
- Система инициализации
- Веб-интерфейс администрирования
- REST API для управления
- Система мониторинга и логирования
- Автоматическое резервное копирование
- Firewall с правилами фильтрации
- Система аутентификации пользователей
- Управление контейнерами
- Управление виртуальными машинами
- Загрузчик BIOS/UEFI
- Документация (техническая и пользовательская)
- Тестовый фреймворк
- Скрипты сборки и установки

### Компоненты

#### Ядро
- `kernel/core/` - Основное ядро
- `kernel/memory/` - Управление памятью
- `kernel/scheduler/` - Планировщик задач
- `kernel/fs/` - Файловая система
- `kernel/net/` - Сетевой стек
- `kernel/drivers/` - Драйверы устройств

#### Драйверы
- `drivers/storage/` - Драйверы хранилищ (ATA/SATA)
- `drivers/network/` - Сетевые драйверы
- `drivers/usb/` - USB драйверы

#### Система
- `system/init/` - Система инициализации
- `system/services/` - Системные сервисы
- `system/libs/` - Системные библиотеки

#### Веб-интерфейс
- `web/admin-panel/` - Панель администрирования
- `web/api/` - REST API

#### Виртуализация
- `virtualization/containers/` - Управление контейнерами
- `virtualization/vms/` - Управление виртуальными машинами

#### Безопасность
- `security/firewall/` - Межсетевой экран
- `security/auth/` - Аутентификация

#### Утилиты
- `monitoring/` - Система мониторинга
- `backup/` - Резервное копирование
- `tools/` - Инструменты разработки

### Известные ограничения
- Поддержка только x86_64 архитектуры
- Максимум 256 задач одновременно
- Максимум 64 сетевых соединений
- Максимум 10 контейнеров
- Максимум 5 виртуальных машин
- Базовая реализация TCP/IP (без полной поддержки всех RFC)
- Простая файловая система без журналирования

### Безопасность
- Базовая аутентификация пользователей
- Firewall с фильтрацией пакетов
- Блокировка учетной записи после 5 неудачных попыток входа
- SSH доступ с настраиваемыми параметрами

### Производительность
- Поддержка до 16GB оперативной памяти
- Поддержка многоядерных процессоров
- Оптимизированное управление памятью
- Эффективный планировщик задач
