🚀 ТРИ ПРОСТЫХ ШАГА

┌─────────────────────────────────────────────────────────────────────────┐
│ ШАГ 1: УСТАНОВИТЕ GIT (2 минуты)                                       │
└─────────────────────────────────────────────────────────────────────────┘

  1. Перейдите на: https://git-scm.com/download/win
  2. Скачайте установщик
  3. Запустите и нажимайте "Next"
  4. Готово!

  Проверка:
    git --version

┌─────────────────────────────────────────────────────────────────────────┐
│ ШАГ 2: НАСТРОЙТЕ GITHUB (2 минуты)                                     │
└─────────────────────────────────────────────────────────────────────────┘

  A. Создайте репозиторий:
     1. Откройте: https://github.com/new
     2. Название: homeserver-os
     3. НЕ ставьте галочку "Add README"
     4. Нажмите "Create repository"

  B. Создайте токен:
     1. Откройте: https://github.com/settings/tokens/new
     2. Название: homeserver-os-token
     3. Выберите: ✅ repo (полный доступ)
     4. Нажмите "Generate token"
     5. СКОПИРУЙТЕ И СОХРАНИТЕ ТОКЕН!
        (выглядит так: ghp_xxxxxxxxxxxx...)

┌─────────────────────────────────────────────────────────────────────────┐
│ ШАГ 3: ЗАПУСТИТЕ СКРИПТ (1 минута)                                     │
└─────────────────────────────────────────────────────────────────────────┘

  1. Откройте PowerShell:
     cd C:\NewProject

  2. Запустите скрипт:
     .\simple-git-push.ps1

  3. Ответьте на вопросы:
     - GitHub username: ваш_username
     - Название репозитория: homeserver-os
     - Метод: 1 (HTTPS)

  4. При запросе введите:
     - Username: ваш_username
     - Password: ваш_токен (ghp_xxxx...)

  5. Готово! Код на GitHub! 🎉

═══════════════════════════════════════════════════════════════════════════

💾 СОХРАНИТЕ ТОКЕН (чтобы не вводить каждый раз)

После первого успешного push выполните:

  git config --global credential.helper store

Теперь Git запомнит токен!

🔑 ВАЖНО О ТОКЕНЕ

  ⚠️  Токен нужно использовать вместо пароля при push
  ⚠️  Сохраните токен в безопасном месте
  ⚠️  Если потеряли - создайте новый

  Где создать токен:
    https://github.com/settings/tokens/new

  Какие права выбрать:
    ✅ repo (полный доступ к репозиториям)
