🚀 САМЫЙ ПРОСТОЙ СПОСОБ (Windows):

1. Откройте проводник Windows
2. Перейдите в папку: C:\Custom-server-os
3. Дважды кликните на файл: git-setup-and-push.bat
4. Следуйте инструкциям на экране

═══════════════════════════════════════════════════════════════════

📋 ЧТО НУЖНО СДЕЛАТЬ ПЕРЕД ЗАПУСКОМ:

1. Создайте репозиторий на GitHub:
   - Перейдите: https://github.com/new
   - Название: custom-server-os
   - Описание: Custom Server OS - Linux Edition
   - НЕ создавайте README, .gitignore, LICENSE
   - Нажмите "Create repository"

2. Скопируйте URL репозитория (будет нужен при запуске скрипта)
   Пример: https://github.com/username/custom-server-os.git

═══════════════════════════════════════════════════════════════════

🔧 АЛЬТЕРНАТИВНЫЙ СПОСОБ (вручную):

Откройте PowerShell или Git Bash в C:\Custom-server-os и выполните:

# 1. Инициализация Git
git init

# 2. Настройка пользователя (если нужно)
git config user.name "Ваше Имя"
git config user.email "your@email.com"

# 3. Добавление удаленного репозитория
git remote add origin https://github.com/username/custom-server-os.git

# 4. Добавление файлов
git add .

# 5. Создание коммита
git commit -m "feat: integrate Linux kernel 6.12.28"

# 6. Отправка на GitHub
git branch -M main
git push -u origin main
