## 🎯 Основные компоненты

### 1. Ядро операционной системы

**Расположение:** `kernel/`

#### Основные модули:
- **kernel.c** - Точка входа ядра, инициализация
- **memory.c** - Управление памятью (постраничное распределение)
- **scheduler.c** - Планировщик задач (round-robin)
- **filesystem.c** - Простая файловая система
- **network.c** - TCP/IP сетевой стек

**Возможности:**
- Поддержка до 256 задач
- 16 GB оперативной памяти
- 64 одновременных сетевых соединения
- 1024 файлов в файловой системе

### 2. Загрузчик

**Расположение:** `bootloader/`

- **boot.asm** - BIOS/UEFI загрузчик
- Переход в защищенный режим
- Загрузка ядра в память
- Передача управления ядру

### 3. Драйверы устройств

**Расположение:** `drivers/`

#### Реализованные драйверы:
- **ATA/SATA** - Драйвер дисковых накопителей
- **Network** - Сетевые карты (базовая поддержка)
- **USB** - USB устройства (заглушка)

### 4. Веб-интерфейс

**Расположение:** `web/`

#### Компоненты:
- **admin-panel/** - Панель администрирования
  - Dashboard с системной информацией
  - Управление сервисами
  - Мониторинг ресурсов
  - Управление виртуализацией
  - Настройки безопасности

- **api/** - REST API
  - `/api/system` - Системная информация
  - `/api/memory` - Информация о памяти
  - `/api/storage` - Информация о хранилище
  - `/api/network` - Сетевая статистика
  - `/api/services` - Управление сервисами
  - `/api/containers` - Управление контейнерами
  - `/api/vms` - Управление виртуальными машинами

### 5. Виртуализация

**Расположение:** `virtualization/`

#### Контейнеры:
- Легковесная виртуализация
- До 10 контейнеров одновременно
- Ограничение ресурсов (CPU, RAM, диск, сеть)
- Управление через API и веб-интерфейс

#### Виртуальные машины:
- Полная виртуализация
- До 5 VM одновременно
- Поддержка BIOS и UEFI
- Настройка CPU, памяти, дисков, сети

### 6. Безопасность

**Расположение:** `security/`

#### Firewall:
- Фильтрация пакетов
- До 256 правил
- Поддержка TCP/UDP/ICMP
- Входящий/исходящий трафик
- Статистика блокировок

#### Аутентификация:
- Управление пользователями
- Хеширование паролей
- Блокировка после 5 неудачных попыток
- Разграничение прав доступа

### 7. Мониторинг

**Расположение:** `monitoring/`

#### Возможности:
- Логирование событий (до 1000 записей)
- Метрики системы (до 50 метрик)
- Статистика ресурсов
- Алерты при превышении порогов
- История событий

### 8. Резервное копирование

**Расположение:** `backup/`

#### Функции:
- Автоматическое резервное копирование
- Полные и инкрементальные бэкапы
- До 30 бэкапов
- Настраиваемое расписание
- Восстановление из бэкапа

## 🎨 Особенности реализации

### Архитектурные решения

1. **Монолитное ядро** - Все компоненты в одном адресном пространстве
2. **Модульная структура** - Четкое разделение компонентов
3. **Простота** - Понятный и читаемый код
4. **Расширяемость** - Легко добавлять новые функции

### Технические детали

- **Архитектура:** x86_64 (64-bit)
- **Язык ядра:** C (стандарт C99)
- **Загрузчик:** NASM Assembly
- **Размер страницы:** 4 KB
- **Размер блока ФС:** 4 KB
- **Сетевой MTU:** 1500 байт
