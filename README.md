## 📋 О проекте

Home Server OS - это легковесная, специализированная операционная система, разработанная специально для домашних серверов. Она предоставляет все необходимые инструменты для управления сервером через удобный веб-интерфейс.

### ✨ Возможности

- 🖥️ **Веб-интерфейс** - Современная панель управления
- 🔌 **REST API** - Полный программный доступ
- 📦 **Контейнеризация** - Легковесная виртуализация приложений
- 💻 **Виртуальные машины** - Полноценная виртуализация
- 💾 **Автоматический бэкап** - Защита данных
- 🔒 **Встроенный Firewall** - Безопасность из коробки
- 📊 **Мониторинг** - Отслеживание ресурсов в реальном времени
- 🌐 **TCP/IP стек** - Полноценная сетевая поддержка

## 🚀 Быстрый старт

### Системные требования

**Минимальные:**
- Процессор: x86_64 (64-bit)
- RAM: 512 MB
- Диск: 4 GB
- Сеть: Ethernet

**Рекомендуемые:**
- Процессор: 2+ ядра x86_64
- RAM: 4 GB+
- Диск: 100 GB+
- Сеть: Gigabit Ethernet

### Установка

#### Вариант 1: Автоматическая установка

```bash
# Клонируйте репозиторий
git clone https://github.com/homeserver-os/homeserver-os.git
cd homeserver-os

# Запустите скрипт быстрого старта
chmod +x quickstart.sh
./quickstart.sh
```

#### Вариант 2: Ручная сборка

```bash
# Установите зависимости (Ubuntu/Debian)
sudo apt-get install build-essential nasm qemu-system-x86 grub-pc-bin xorriso

# Соберите проект
make all

# Создайте ISO образ
make iso

# Протестируйте в QEMU
make run
```

#### Вариант 3: Установка на физическое оборудование

```bash
# Создайте загрузочный USB
sudo dd if=build/homeserver.iso of=/dev/sdX bs=4M status=progress

# Или используйте установщик
sudo ./tools/install.sh
```

```
│   ├── net/               # Сетевой стек
│   └── drivers/           # Драйверы устройств
├── 🚀 bootloader/         # Загрузчик BIOS/UEFI
├── ⚙️ system/             # Системные компоненты
│   ├── init/              # Система инициализации
│   ├── services/          # Системные сервисы
│   └── libs/              # Библиотеки
├── 💾 drivers/            # Драйверы устройств
│   ├── storage/           # ATA/SATA драйверы
│   ├── network/           # Сетевые драйверы
│   └── usb/               # USB драйверы
├── 🌐 web/                # Веб-интерфейс
│   ├── admin-panel/       # Панель администрирования
│   └── api/               # REST API
├── 📦 virtualization/     # Виртуализация
│   ├── containers/        # Контейнеры
│   └── vms/               # Виртуальные машины
├── 🔒 security/           # Безопасность
│   ├── firewall/          # Межсетевой экран
│   └── auth/              # Аутентификация
├── 📊 monitoring/         # Мониторинг системы
├── 💾 backup/             # Резервное копирование
├── 📖 docs/               # Документация
├── 🧪 tests/              # Тесты
└── 🛠️ tools/              # Инструменты разработки
```

## 🖥️ Веб-интерфейс

После установки откройте браузер и перейдите по адресу:

```
http://IP_АДРЕС_СЕРВЕРА:8080
```

**Данные для входа по умолчанию:**
- Логин: `admin`
- Пароль: `admin`

⚠️ **Важно:** Измените пароль при первом входе!

### Скриншоты

Веб-интерфейс предоставляет:
- Dashboard с системной информацией
- Управление сервисами
- Мониторинг ресурсов
- Управление контейнерами и VM
- Настройки безопасности
- Резервное копирование

## 🔌 REST API

Полный программный доступ через REST API:

```bash
# Системная информация
curl http://localhost:8081/api/system

# Информация о памяти
curl http://localhost:8081/api/memory

# Список сервисов
curl http://localhost:8081/api/services

# Управление сервисом
curl -X POST http://localhost:8081/api/services \
  -H "Content-Type: application/json" \
  -d '{"name":"web","action":"restart"}'
```

Полная документация API: [docs/technical.md](docs/technical.md)
