FIRST TIME SETUP (5 MINUTES):

  1. Install Git:
     https://git-scm.com/download/win

  2. Create GitHub repository:
     - Go to: https://github.com/new
     - Name: homeserver-os
     - DO NOT check "Add README"
     - Click "Create repository"

  3. Create Personal Access Token:
     - Go to: https://github.com/settings/tokens/new
     - Name: homeserver-os-token
     - Select: repo (full access)
     - Click "Generate token"
     - SAVE THE TOKEN! (looks like: ghp_xxxxxxxxxxxx...)

  4. Double-click git-push.bat

  5. Enter your username and repository name

  6. When Git asks for password, enter your TOKEN (not password!)

  7. Done! Code is on GitHub!
