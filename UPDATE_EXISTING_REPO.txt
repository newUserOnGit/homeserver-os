═══════════════════════════════════════════════════════════════════

ШАГ 1: Перейдите в директорию с обновленным проектом
------------------------------------------------------

cd /c/Custom-server-os

═══════════════════════════════════════════════════════════════════

ШАГ 2: Инициализируйте Git (если еще не сделано)
-------------------------------------------------

git init

═══════════════════════════════════════════════════════════════════

ШАГ 3: Добавьте ваш существующий репозиторий
---------------------------------------------

# Если выдаст ошибку "remote origin already exists", выполните:

ШАГ 4: Создайте .gitignore (чтобы не загружать лишнее)
-------------------------------------------------------

cat > .gitignore << 'EOF'

ШАГ 7: Получите последние изменения из репозитория
---------------------------------------------------

# Сначала получим изменения из удаленного репозитория
git fetch origin main

# Объединим с локальными изменениями (разрешим несвязанные истории)
git pull origin main --allow-unrelated-histories --no-rebase

# Если возникнут конфликты, разрешите их и выполните:
# git add .
# git commit -m "merge: resolve conflicts"

═══════════════════════════════════════════════════════════════════

ШАГ 8: Отправьте изменения на GitHub
-------------------------------------

git push origin main

═══════════════════════════════════════════════════════════════════

⚠️ ВАЖНО - РАЗМЕР РЕПОЗИТОРИЯ:

Проект занимает ~1.6 GB из-за ядра Linux.
GitHub может отклонить файлы >100MB.

ЕСЛИ ВОЗНИКНЕТ ОШИБКА "file too large":

Вариант 1: Исключить ядро из репозитория
-----------------------------------------
echo "linux-kernel/" >> .gitignore
git rm -r --cached linux-kernel/
git add .gitignore
git commit -m "chore: exclude linux kernel from repository

Linux kernel source (1.6GB) excluded from Git.
Download separately from: https://kernel.org/
Version: 6.12.28"
git push origin main

Вариант 2: Использовать Git LFS
--------------------------------
git lfs install
git lfs track "linux-kernel/**/*.c"
git lfs track "linux-kernel/**/*.h"
git add .gitattributes
git commit -m "chore: add Git LFS for large files"
git push origin main
