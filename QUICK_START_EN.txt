🚀 THREE SIMPLE STEPS TO PUSH TO GITHUB

┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 1: INSTALL GIT (2 minutes)                                        │
└─────────────────────────────────────────────────────────────────────────┘

  1. Go to: https://git-scm.com/download/win
  2. Download installer
  3. Run and click "Next"
  4. Done!

  Check:
    git --version

┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 2: SETUP GITHUB (2 minutes)                                       │
└─────────────────────────────────────────────────────────────────────────┘

  A. Create repository:
     1. Open: https://github.com/new
     2. Name: homeserver-os
     3. DO NOT check "Add README"
     4. Click "Create repository"

  B. Create token:
     1. Open: https://github.com/settings/tokens/new
     2. Name: homeserver-os-token
     3. Select: ✅ repo (full access)
     4. Click "Generate token"
     5. COPY AND SAVE THE TOKEN!
        (looks like: ghp_xxxxxxxxxxxx...)

┌─────────────────────────────────────────────────────────────────────────┐
│ STEP 3: RUN SCRIPT (1 minute)                                          │
└─────────────────────────────────────────────────────────────────────────┘

  1. Open PowerShell:
     cd C:\NewProject

  2. Run script:
     .\simple-git-push.ps1

  3. Answer questions:
     - GitHub username: your_username
     - Repository name: homeserver-os
     - Method: 1 (HTTPS)

  4. When asked, enter:
     - Username: your_username
     - Password: your_token (ghp_xxxx...)

  5. Done! Code is on GitHub! 🎉

═══════════════════════════════════════════════════════════════════════════

💾 SAVE TOKEN (so you don't have to enter it every time)

After first successful push, run:

  git config --global credential.helper store

Now Git will remember your token!

═══════════════════════════════════════════════════════════════════════════

📝 DAILY USE

When you need to push changes:

  cd C:\NewProject
  .\simple-git-push.ps1

Enter message or press Enter. Done!
