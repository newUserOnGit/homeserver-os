🚀 БЫСТРАЯ УСТАНОВКА UBUNTU

═══════════════════════════════════════════════════════════════════════════

Шаг 1: Установка Ubuntu
------------------------

Откройте PowerShell и выполните:

wsl --install Ubuntu

Это установит Ubuntu (последняя версия).

Альтернативно, для Ubuntu 22.04 LTS:

wsl --install Ubuntu-22.04

Шаг 2: Дождитесь завершения установки
--------------------------------------

Установка займет 2-5 минут.
Вы увидите прогресс загрузки и установки.

Шаг 3: Первый запуск
--------------------

После установки автоматически откроется окно Ubuntu.
Создайте пользователя:

Enter new UNIX username: ваше_имя
New password: ваш_пароль
Retype new password: ваш_пароль

Шаг 4: Обновление системы
--------------------------

В терминале Ubuntu выполните:

sudo apt update
sudo apt upgrade -y

═══════════════════════════════════════════════════════════════════════════

📦 УСТАНОВКА ЗАВИСИМОСТЕЙ ДЛЯ СБОРКИ ЯДРА

═══════════════════════════════════════════════════════════════════════════

После установки Ubuntu выполните:

sudo apt install -y \
    build-essential \
    gcc \
    g++ \
    make \
    bison \
    flex \
    libssl-dev \
    libelf-dev \
    bc \
    cpio \
    gzip \
    grub-pc-bin \
    xorriso \
    qemu-system-x86

Это установит все необходимое для сборки ядра Linux.

═══════════════════════════════════════════════════════════════════════════

🔧 ПЕРЕХОД К ПРОЕКТУ

═══════════════════════════════════════════════════════════════════════════

В Ubuntu терминале:

cd /mnt/c/Custom-server-os

Теперь вы в директории проекта!

═══════════════════════════════════════════════════════════════════════════

🚀 СБОРКА ЯДРА

═══════════════════════════════════════════════════════════════════════════

Шаг 1: Проверка зависимостей
-----------------------------

make check

Шаг 2: Сборка ядра (автоматически)
-----------------------------------

bash build/scripts/build-kernel.sh

Или вручную:

cd linux-kernel/source
cp ../../config/kernel.config .config
make olddefconfig
make -j$(nproc)
make modules -j$(nproc)

Шаг 3: Ожидание (30-60 минут)
------------------------------

Сборка займет время. Можете:
- Оставить терминал открытым
- Заняться другими делами
- Следить за прогрессом

═══════════════════════════════════════════════════════════════════════════

✅ КОМАНДЫ ДЛЯ КОПИРОВАНИЯ

═══════════════════════════════════════════════════════════════════════════

# 1. Установка Ubuntu (в PowerShell)
wsl --install Ubuntu

# 2. После установки и создания пользователя (в Ubuntu)
sudo apt update && sudo apt upgrade -y

# 3. Установка зависимостей
sudo apt install -y build-essential gcc g++ make bison flex libssl-dev libelf-dev bc cpio gzip grub-pc-bin xorriso qemu-system-x86

# 4. Переход в проект
cd /mnt/c/Custom-server-os

# 5. Проверка
make check

# 6. Сборка
bash build/scripts/build-kernel.sh
