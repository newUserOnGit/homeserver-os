    • Поддержка до 256 задач одновременно
    • Управление памятью (до 16 GB)
    • TCP/IP сетевой стек (до 64 соединений)
    • Файловая система (до 1024 файлов)

  📦 Виртуализация:
    • Контейнеры (до 10 одновременно)
    • Виртуальные машины (до 5 одновременно)
    • Ограничение ресурсов (CPU, RAM, диск, сеть)

  🔒 Безопасность:
    • Firewall (до 256 правил)
    • Аутентификация пользователей (до 64 пользователей)
    • Блокировка после неудачных попыток входа
    • SSH доступ

  📊 Мониторинг:
    • Логирование событий (до 1000 записей)
    • Метрики системы (до 50 метрик)
    • Алерты при превышении порогов
    • Статистика ресурсов в реальном времени

  💾 Резервное копирование:
    • Автоматические бэкапы
    • Полные и инкрементальные копии
    • Хранение до 30 бэкапов
    • Настраиваемое расписание

🚀 БЫСТРЫЙ СТАРТ

  1. Проверка статуса:
     ./status.sh

  2. Сборка проекта:
     make all

  3. Запуск тестов:
     cd tests && ./run_tests.sh

  4. Тестирование в QEMU:
     make run

  5. Установка на диск:
     sudo ./tools/install.sh
