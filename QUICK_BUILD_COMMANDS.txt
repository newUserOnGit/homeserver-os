🚀 АВТОМАТИЧЕСКАЯ СБОРКА (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════════════════════

cd /mnt/c/Custom-server-os
bash build/scripts/build-kernel.sh

═══════════════════════════════════════════════════════════════════════════

🔧 РУЧНАЯ СБОРКА (ПОШАГОВО)
═══════════════════════════════════════════════════════════════════════════

# Шаг 1: Перейти в проект
cd /mnt/c/Custom-server-os

# Шаг 2: Скопировать конфигурацию
cp config/kernel.config linux-kernel/source/.config

# Шаг 3: Перейти в исходники ядра
cd linux-kernel/source

# Шаг 4: Настроить конфигурацию
make olddefconfig

# Шаг 5: Собрать ядро
make -j$(nproc)

# Шаг 6: Собрать модули
make modules -j$(nproc)

═══════════════════════════════════════════════════════════════════════════

⚡ ОДНОЙ КОМАНДОЙ
═══════════════════════════════════════════════════════════════════════════

cd /mnt/c/Custom-server-os && cp config/kernel.config linux-kernel/source/.config && cd linux-kernel/source && make olddefconfig && make -j$(nproc) && make modules -j$(nproc)

═══════════════════════════════════════════════════════════════════════════

📊 ЧТО ПРОИСХОДИТ
═══════════════════════════════════════════════════════════════════════════

make olddefconfig  → Обновляет конфигурацию (1-2 мин)
make -j$(nproc)    → Компилирует ядро (30-60 мин)
make modules       → Компилирует модули (10-20 мин)

═══════════════════════════════════════════════════════════════════════════

✅ ПРОВЕРКА УСПЕШНОЙ СБОРКИ
═══════════════════════════════════════════════════════════════════════════

После завершения проверьте:

ls -lh arch/x86/boot/bzImage

Если файл существует - сборка успешна!

═══════════════════════════════════════════════════════════════════════════

❌ ЕСЛИ ОШИБКА
═══════════════════════════════════════════════════════════════════════════

   ls -la .config

   sudo apt install -y build-essential gcc make bison flex libssl-dev libelf-dev bc
