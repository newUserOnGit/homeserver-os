🚀 СЛЕДУЮЩИЕ ШАГИ:

1. Перейдите в Linux окружение (WSL2/VM/Native Linux)

2. Установите зависимости:
   
   Ubuntu/Debian:
   $ sudo apt-get install build-essential gcc make \
     grub-pc-bin xorriso cpio gzip qemu-system-x86

   Fedora:
   $ sudo dnf install gcc make grub2-tools xorriso \
     cpio gzip qemu-system-x86

3. Перейдите в директорию проекта:
   
   WSL:
   $ cd /mnt/c/Custom-server-os
   
   Linux:
   $ cd /path/to/Custom-server-os

4. Проверьте зависимости:
   $ make check

5. Соберите проект (30-60 минут):
   $ make all

6. Протестируйте в QEMU:
   $ make test
