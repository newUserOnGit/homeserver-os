🚀 ЧТО ДЕЛАТЬ ДАЛЬШЕ:

   Вариант 1: Сборка в WSL2 (Windows Subsystem for Linux)
   -------------------------------------------------------
   1. Установите WSL2:
      > wsl --install
   
   2. Перезагрузите компьютер
   
   3. Откройте WSL и перейдите в проект:
      $ cd /mnt/c/Custom-server-os
   
   4. Установите зависимости:
      $ sudo apt-get update
      $ sudo apt-get install build-essential gcc make \
        grub-pc-bin xorriso cpio gzip qemu-system-x86
   
   5. Соберите проект:
      $ make all
   
   6. Протестируйте:
      $ make test

   Вариант 2: Сборка в Linux VM
   -----------------------------
   1. Создайте Linux VM (Ubuntu/Debian)
   2. Скопируйте проект в VM
   3. Установите зависимости (см. выше)
   4. Соберите проект: make all

   Вариант 3: Сборка на нативном Linux
   ------------------------------------
   1. Скопируйте проект на Linux машину
   2. Установите зависимости
   3. Соберите: make all
