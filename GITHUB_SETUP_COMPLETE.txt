🚀 КАК ИСПОЛЬЗОВАТЬ

┌─────────────────────────────────────────────────────────────────────────┐
│ ШАГ 1: ПЕРВОНАЧАЛЬНАЯ НАСТРОЙКА (ОДИН РАЗ)                             │
└─────────────────────────────────────────────────────────────────────────┘

  1. Откройте PowerShell в папке проекта:

     cd C:\NewProject

  2. Запустите скрипт настройки:

     .\github-setup.ps1

  3. Следуйте инструкциям на экране:
     - Введите ваше имя и email
     - Выберите метод аутентификации (рекомендуется GitHub CLI)
     - Введите название репозитория
     - Готово! Скрипт создаст репозиторий и отправит код

┌─────────────────────────────────────────────────────────────────────────┐
│ ШАГ 2: ЕЖЕДНЕВНОЕ ИСПОЛЬЗОВАНИЕ                                        │
└─────────────────────────────────────────────────────────────────────────┘

  Когда нужно отправить изменения на GitHub:

  1. Откройте PowerShell:

     cd C:\NewProject

  2. Запустите скрипт:

     .\git-push.ps1

  3. Введите сообщение коммита или нажмите Enter для автоматического

  4. Готово! Изменения на GitHub

💡 РЕКОМЕНДУЕМАЯ НАСТРОЙКА

Для максимального удобства рекомендую использовать GitHub CLI:

  1. Установите GitHub CLI:

     winget install GitHub.cli

  2. Авторизуйтесь:

     gh auth login

  3. Теперь все скрипты будут работать автоматически!

Перед использованием убедитесь:

      Установка: winget install GitHub.cli

      Регистрация: https://github.com/signup

  [ ] Готовы создать репозиторий
      Название: homeserver-os (или любое другое)
