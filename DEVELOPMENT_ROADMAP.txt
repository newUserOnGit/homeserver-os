5. REST API
   Приоритет: 🟡 ВЫСОКИЙ

   Endpoints:

   Система:
   GET  /api/system          # Системная информация
   GET  /api/system/cpu      # Информация о CPU
   GET  /api/system/memory   # Информация о памяти
   GET  /api/system/disk     # Информация о дисках
   GET  /api/system/network  # Сетевая статистика

   Сервисы:
   GET  /api/services        # Список сервисов
   POST /api/services/:name/start
   POST /api/services/:name/stop
   POST /api/services/:name/restart
   GET  /api/services/:name/logs

   Контейнеры:
   GET  /api/containers      # Список контейнеров
   POST /api/containers      # Создать контейнер
   GET  /api/containers/:id
   DELETE /api/containers/:id
   POST /api/containers/:id/start
   POST /api/containers/:id/stop

   Виртуальные машины:
   GET  /api/vms             # Список VM
   POST /api/vms             # Создать VM
   GET  /api/vms/:id
   DELETE /api/vms/:id
   POST /api/vms/:id/start
   POST /api/vms/:id/stop

   Мониторинг:
   GET  /api/monitoring      # Метрики мониторинга
   GET  /api/monitoring/history
   POST /api/monitoring/alerts

   Аутентификация:
   POST /api/auth/login      # Аутентификация
   POST /api/auth/logout
   GET  /api/auth/user
