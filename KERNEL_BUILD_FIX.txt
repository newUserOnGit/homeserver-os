🔍 ПРИЧИНА ОШИБКИ
═══════════════════════════════════════════════════════════════════════════

Вы пытались запустить make в директории linux-kernel/, но исходники ядра
находятся в linux-kernel/source/

Структура:
  linux-kernel/          ← здесь НЕТ Makefile ядра
  linux-kernel/source/   ← здесь ЕСТЬ Makefile ядра

═══════════════════════════════════════════════════════════════════════════

✅ ПРАВИЛЬНЫЕ КОМАНДЫ ДЛЯ РУЧНОЙ СБОРКИ
═══════════════════════════════════════════════════════════════════════════

В WSL Ubuntu выполните:

# 1. Перейдите в директорию проекта
cd /mnt/c/Custom-server-os

# 2. Скопируйте конфигурацию в правильное место
cp config/kernel.config linux-kernel/source/.config

# 3. Перейдите в директорию с исходниками ядра
cd linux-kernel/source

# 4. Настройте конфигурацию
make olddefconfig

# 5. Соберите ядро (используя все ядра процессора)
make -j$(nproc)

# 6. Соберите модули
make modules -j$(nproc)

═══════════════════════════════════════════════════════════════════════════

🚀 ИЛИ ИСПОЛЬЗУЙТЕ АВТОМАТИЧЕСКИЙ СКРИПТ (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════════════════════

Скрипт нужно исправить, но пока используйте эти команды:

cd /mnt/c/Custom-server-os
bash build/scripts/build-kernel.sh

Если скрипт не работает, используйте ручные команды выше.

═══════════════════════════════════════════════════════════════════════════

📋 КОМАНДЫ ДЛЯ КОПИРОВАНИЯ (WSL Ubuntu)
═══════════════════════════════════════════════════════════════════════════

cd /mnt/c/Custom-server-os && cp config/kernel.config linux-kernel/source/.config && cd linux-kernel/source && make olddefconfig && make -j$(nproc) && make modules -j$(nproc)

═══════════════════════════════════════════════════════════════════════════

⏱️ ВРЕМЯ СБОРКИ
═══════════════════════════════════════════════════════════════════════════

make olddefconfig:    1-2 минуты
make -j$(nproc):      30-60 минут (зависит от процессора)
make modules:         10-20 минут

ИТОГО:                40-80 минут

💡 ПРОВЕРКА ПРОГРЕССА
═══════════════════════════════════════════════════════════════════════════

  CC [M]  drivers/...
  LD      vmlinux

Это нормально - идет компиляция!
