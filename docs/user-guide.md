## Введение

Home Server OS - это специализированная операционная система для домашних серверов, разработанная для простоты использования и максимальной функциональности.

### Основные возможности
- Веб-интерфейс для управления
- REST API для автоматизации
- Контейнеризация приложений
- Виртуальные машины
- Автоматическое резервное копирование
- Встроенный firewall
- Мониторинг системы в реальном времени

## Системные требования

### Минимальные требования
- Процессор: x86_64 (64-bit)
- Оперативная память: 512 MB
- Дисковое пространство: 4 GB
- Сетевая карта: Ethernet

### Рекомендуемые требования
- Процессор: 2+ ядра x86_64
- Оперативная память: 4 GB+
- Дисковое пространство: 100 GB+
- Сетевая карта: Gigabit Ethernet

## Установка

### Способ 1: Установка с ISO образа

1. Скачайте ISO образ `homeserver.iso`
2. Запишите на USB флешку:
   ```bash
   dd if=homeserver.iso of=/dev/sdX bs=4M status=progress
   ```
3. Загрузитесь с USB
4. Следуйте инструкциям установщика

### Способ 2: Автоматическая установка

```bash
sudo ./tools/install.sh
```

### Способ 3: Установка в виртуальной машине

#### QEMU
```bash
qemu-system-x86_64 -cdrom homeserver.iso -m 2048 -boot d
```

#### VirtualBox
1. Создайте новую VM
2. Тип: Linux, Версия: Other Linux (64-bit)
3. RAM: минимум 512 MB
4. Подключите ISO
5. Запустите установку

## Первый запуск

### Вход в систему

По умолчанию:
- **Логин**: `admin`
- **Пароль**: `admin`

⚠️ **Важно**: Измените пароль при первом входе!

### Базовая настройка

1. Измените пароль администратора:
   ```bash
   passwd admin
   ```

2. Настройте сеть:
   ```bash
   nano /etc/network.conf
   ```

3. Установите имя хоста:
   ```bash
   echo "my-server" > /etc/hostname
   ```

4. Перезагрузите систему:
   ```bash
   reboot
   ```

## Управление сервисами

### Через веб-интерфейс

1. Перейдите в раздел "Сервисы"
2. Выберите нужный сервис
3. Нажмите "Запустить" или "Остановить"

### Через командную строку

```bash
# Запустить сервис
service start <имя_сервиса>

# Остановить сервис
service stop <имя_сервиса>

# Перезапустить сервис
service restart <имя_сервиса>

# Статус сервиса
service status <имя_сервиса>
```

### Доступные сервисы

- **web** - Веб-сервер
- **ssh** - SSH сервер
- **dns** - DNS сервер
- **dhcp** - DHCP сервер
- **ftp** - FTP сервер
- **samba** - Samba файловый сервер

## Виртуализация

### Контейнеры

#### Создание контейнера

Через веб-интерфейс:
1. Виртуализация → Контейнеры
2. Нажмите "Создать контейнер"
3. Заполните параметры:
   - Имя
   - Образ
   - Ресурсы (CPU, RAM)
   - Порты
4. Нажмите "Создать"

Через API:
```bash
curl -X POST http://localhost:8081/api/containers \
  -H "Content-Type: application/json" \
  -d '{
    "name": "web-app",
    "image": "nginx:latest",
    "cpu_limit": 50,
    "memory_limit": 512
  }'
```

#### Управление контейнерами

```bash
# Список контейнеров
container list

# Запустить контейнер
container start <id>

# Остановить контейнер
container stop <id>

# Удалить контейнер
container delete <id>
```

### Виртуальные машины

#### Создание VM

1. Виртуализация → Виртуальные машины
2. Нажмите "Создать VM"
3. Настройте параметры:
   - Имя
   - CPU (количество ядер)
   - RAM (в MB)
   - Диск (размер в GB)
   - Сеть
4. Нажмите "Создать"

#### Управление VM

```bash
# Список VM
vm list

# Запустить VM
vm start <id>

# Остановить VM
vm stop <id>

# Приостановить VM
vm pause <id>

# Удалить VM
vm delete <id>
```

## Резервное копирование

### Автоматическое резервное копирование

По умолчанию система создает ежедневные бэкапы.

Настройка:
1. Резервное копирование → Настройки
2. Установите параметры:
   - Тип бэкапа (полный/инкрементальный)
   - Расписание
   - Хранение (количество дней)
3. Сохраните

### Ручное создание бэкапа

Через веб-интерфейс:
1. Резервное копирование → Создать
2. Выберите тип бэкапа
3. Добавьте описание
4. Нажмите "Создать"

Через командную строку:
```bash
backup create --type full --description "Ручной бэкап"
```

### Восстановление из бэкапа

```bash
# Список бэкапов
backup list

# Восстановить бэкап
backup restore <backup_id> --path /restore
```

## Безопасность

### Firewall

#### Добавление правила

Через веб-интерфейс:
1. Безопасность → Firewall
2. Нажмите "Добавить правило"
3. Настройте:
   - Действие (разрешить/запретить)
   - Протокол (TCP/UDP/ICMP)
   - Порт
   - IP адрес
4. Сохраните

Через командную строку:
```bash
firewall add --action allow --protocol tcp --port 80 --description "HTTP"
```

#### Управление firewall

```bash
# Включить firewall
firewall enable

# Отключить firewall
firewall disable

# Статус
firewall status

# Список правил
firewall list
```

### SSH

#### Настройка SSH

Редактируйте `/etc/ssh/sshd_config`:
```bash
Port 22
PermitRootLogin no
PasswordAuthentication yes
```

Перезапустите SSH:
```bash
service restart ssh
```

### Пользователи

#### Создание пользователя

```bash
useradd -m -s /bin/bash username
passwd username
```

#### Управление правами

```bash
# Добавить в группу admin
usermod -aG admin username

# Удалить пользователя
userdel username
```

## Устранение неполадок

### Система не загружается

1. Загрузитесь в режиме восстановления
2. Проверьте логи: `/var/log/system.log`
3. Восстановите из бэкапа при необходимости

### Нет доступа к веб-интерфейсу

1. Проверьте статус веб-сервера:
   ```bash
   service status web
   ```

2. Проверьте firewall:
   ```bash
   firewall list | grep 8080
   ```

3. Проверьте сетевые настройки:
   ```bash
   ip addr show
   ```

### Высокая загрузка системы

1. Проверьте процессы:
   ```bash
   top
   ```

2. Проверьте использование диска:
   ```bash
   df -h
   ```

3. Проверьте логи:
   ```bash
   tail -f /var/log/system.log
   ```

### Проблемы с контейнерами

1. Проверьте статус:
   ```bash
   container list
   ```

2. Проверьте логи контейнера:
   ```bash
   container logs <id>
   ```

3. Перезапустите контейнер:
   ```bash
   container restart <id>
   ```

## Часто задаваемые вопросы

**Q: Как изменить порт веб-интерфейса?**
A: Отредактируйте `/etc/system.conf` и измените параметр `web_admin_port`.

**Q: Можно ли запустить несколько VM одновременно?**
A: Да, до 5 VM по умолчанию. Лимит можно изменить в настройках.

**Q: Как обновить систему?**
A: Используйте команду `system update` или через веб-интерфейс.

**Q: Поддерживается ли RAID?**
A: Да, поддерживаются RAID 0, 1, 5, 10.

**Q: Можно ли использовать внешние диски?**
A: Да, система автоматически определяет подключенные диски.
