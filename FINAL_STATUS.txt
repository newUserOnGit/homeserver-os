🚀 СЛЕДУЮЩИЕ ШАГИ

Для продолжения работы выполните:

1. Перейдите в Linux окружение (WSL2/VM/Native Linux)

2. Установите зависимости:
   Ubuntu/Debian:
   $ sudo apt-get install build-essential gcc make \
     grub-pc-bin xorriso cpio gzip qemu-system-x86

3. Перейдите в директорию проекта:
   $ cd /mnt/c/Custom-server-os  # в WSL

4. Проверьте зависимости:
   $ make check

5. Соберите проект (30-60 минут):
   $ make all

6. Протестируйте в QEMU:
   $ make test

🔧 КОМАНДЫ MAKEFILE

make help       - Показать все доступные команды
make check      - Проверить системные зависимости
make kernel     - Собрать только ядро Linux
make rootfs     - Создать только корневую ФС
make iso        - Создать только ISO образ
make all        - Собрать всё (kernel + rootfs + iso)
make test       - Тестировать в QEMU (512MB RAM)
make run        - Алиас для make test
make run-2g     - Тестировать с 2GB RAM
make run-net    - Тестировать с сетью
make info       - Показать информацию о сборке
make clean      - Очистить артефакты сборки
make distclean  - Полная очистка (включая ядро)
